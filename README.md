# 🏎️ Sistema de Banco de Dados — Fórmula 1

## 📌 Sobre o projeto

Este projeto acadêmico tem como objetivo desenvolver um banco de dados para representar informações relacionadas ao universo da Fórmula 1.

O banco foi criado utilizando MySQL, com tabelas relacionadas a países, equipes, pilotos, corridas e participantes.

## 🎯 Objetivos

- Criar um banco de dados relacional.
- Implementar tabelas e seus relacionamentos.
- Utilizar chaves primárias (PRIMARY KEY).
- Utilizar chaves estrangeiras (FOREIGN KEY).
- Praticar comandos SQL.

## 🛠️ Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL

## 📂 Arquivo do projeto

- `trabalho-formula1.sql` — script SQL para criação e implementação do banco de dados.

## ▶️ Como executar

1. Instale o MySQL Server e o MySQL Workbench.
2. Abra o MySQL Workbench.
3. Abra o arquivo `trabalho-formula1.sql`.
4. Execute o script no banco de dados.
5. Confira as tabelas criadas.

## 📚 Aprendizados

Com este projeto, pratiquei conceitos de modelagem de dados, criação de tabelas, definição de chaves primárias e estrangeiras e utilização da linguagem SQL.
