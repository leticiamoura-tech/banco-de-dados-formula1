# 🏎️ Banco de Dados — Fórmula 1

## Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica da disciplina de Banco de Dados, no curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é criar um banco de dados relacional para organizar informações relacionadas ao universo da Fórmula 1, utilizando SQL e MySQL Workbench.

## Objetivos

- Criar um banco de dados relacional.
- Criar tabelas e seus relacionamentos.
- Utilizar chaves primárias (PRIMARY KEY).
- Utilizar chaves estrangeiras (FOREIGN KEY).
- Inserir, atualizar e consultar dados.

## Tecnologias utilizadas

- MySQL
- SQL
- MySQL Workbench

## Estrutura do banco de dados

O banco de dados contém cinco tabelas:

- Países
- Equipes
- Pilotos
- Corridas
- Participantes

## Arquivo do projeto

`trabalho-formula1.sql` — script SQL para criação e implementação do banco de dados.

## Como executar

1. Instale o MySQL Server e o MySQL Workbench.
2. Abra o MySQL Workbench.
3. Abra o arquivo `trabalho-formula1.sql`.
4. Conecte-se ao servidor MySQL.
5. Execute o script SQL.
6. Confira as tabelas criadas.

## Aprendizados

Com este projeto, pratiquei conceitos de modelagem de dados, criação de tabelas, definição de chaves primárias e estrangeiras e utilização de comandos SQL.
