Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica da disciplina de Banco de Dados, no curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é criar um banco de dados para organizar informações relacionadas à Fórmula 1, utilizando a linguagem SQL e o MySQL Workbench.

Tecnologias utilizadas

* MySQL
* SQL
* MySQL Workbench

Estrutura do banco de dados

O banco de dados contém tabelas para organizar as informações sobre:

* Países
* Equipes
* Pilotos
* Corridas
* Participantes

Como executar o projeto

1. Abra o MySQL Workbench.
2. Abra o arquivo Fórmula 1.sql.
3. Conecte-se ao seu servidor MySQL.
4. Execute o script SQL para criar e estruturar o banco de dados.

Objetivo acadêmico

Praticar conceitos de banco de dados, criação de tabelas, chaves primárias, relacionamentos e comandos SQL.

## 📌 Sobre o projeto

Este projeto acadêmico tem como objetivo desenvolver um banco de dados para representar informações relacionadas ao universo da Fórmula 1.

O banco foi criado utilizando MySQL, com tabelas relacionadas a países, equipes, pilotos, corridas e participantes.

## 🎯 Objetivos

- Criar um banco de dados relacional.
- Implementar tabelas e seus relacionamentos.
- Utilizar chaves primárias (PRIMARY KEY).
- Utilizar chaves estrangeiras (FOREIGN KEY).
- Praticar comandos SQL.

## 🛠️ Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL

## 📂 Arquivo do projeto

- `trabalho-formula1.sql` — script SQL para criação e implementação do banco de dados.

## ▶️ Como executar

1. Instale o MySQL Server e o MySQL Workbench.
2. Abra o MySQL Workbench.
3. Abra o arquivo `trabalho-formula1.sql`.
4. Execute o script no banco de dados.
5. Confira as tabelas criadas.

## 📚 Aprendizados

Com este projeto, pratiquei conceitos de modelagem de dados, criação de tabelas, definição de chaves primárias e estrangeiras e utilização da linguagem SQL.
